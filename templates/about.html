About & methodology

Implemented features and future work are listed separately below. Nothing here is clinically validated.

Problem statement

Manual delineation of brain tumours on multimodal MRI is time-consuming and variable. This project integrates automated segmentation, radiomics and reporting in one reproducible web workflow for research.

Objectives

  • Validate and ingest T1, T1ce, T2, FLAIR NIfTI volumes.
  • Segment tumour sub-regions with a supplied U-Net/ResNet34 checkpoint.
  • Extract PyRadiomics features per region and modality.
  • Evaluate against a reference mask when available.
  • Produce reproducible reports and metadata.

Dataset

BraTS 2020 (labels 0 background, 1 necrotic/non-enhancing core, 2 edema, 4 enhancing tumour). The dataset is not bundled; users supply their own copy.

U-Net with ResNet34 encoder

U-Net is an encoder–decoder CNN with skip connections. The encoder is a ResNet34 (via segmentation-models-pytorch) with 4 input channels (one per modality); the decoder up-samples to 4 class logits per pixel. Inference is slice-wise (2-D) over axial slices.

Process

  1. Segmentation: validation → configurable normalisation → zero-padding to multiple of 32 → argmax → configured class-to-BraTS-label mapping → NIfTI with original affine/header.
  2. Regions: WT = {1,2,4}, TC = {1,4}, ET = {4}; volume (mL) = voxels × voxel mm³ / 1000.
  3. Radiomics: PyRadiomics, 3-D, settings in radiomics_analysis/settings.yaml, stored per run; no resampling by default.
  4. Evaluation: Dice, IoU, precision, recall, specificity, HD95 (mm, physical spacing) with an explicit empty-mask policy.

Implemented

  • All steps above, SQLite history, PDF report, metadata export, human-review flag, persisted job states.

Limitations

  • Training preprocessing and class mapping were not verified against training code unless you set the flags in model_config.yaml.
  • Training/test patient provenance of the checkpoint is unknown, so no independent test performance is claimed.
  • No clinical validation, no regulatory approval, no authentication (single-user local deployment), no formal security audit.
  • Radiomics values depend on segmentation quality and settings; not full IBSI compliance.

Future scope (NOT implemented)

  • 3-D / ensemble models and model comparison on a patient-wise split.
  • Grad-CAM-style interpretability for segmentation.
  • Multi-user authentication and access control.
  • External-cohort validation and IBSI benchmark validation.
