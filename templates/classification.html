What is needed to enable it

  • A trained classifier checkpoint (e.g. ResNet50) and its training code: class names/order, input size, preprocessing.
  • Labels. The BraTS 2020 training set provides a per-patient HGG/LGG grade (folder / name_mapping.csv), so a separate HGG-vs-LGG classifier could be trained on a patient-wise split; it must not be trained on slices of the same patient that appear in the test set. Training such a model was not done here.
  • Held-out evaluation (accuracy, precision, recall, F1, confusion matrix) before any prediction is shown.
