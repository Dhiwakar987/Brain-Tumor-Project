Academic research prototype. Not clinically validated.

1. Multimodal MRI Input

The system uses four MRI modalities:

  • T1: Shows brain anatomical structure.
  • T1ce: Highlights contrast-enhanced regions.
  • T2: Shows fluid and abnormal tissue changes.
  • FLAIR: Highlights abnormal signal regions.

Each modality provides complementary information about brain tissue.

2. Segmentation Model

  • Architecture: U-Net
  • Encoder: ResNet34
  • Input channels: 4
  • Output classes: 4
  • Model checkpoint: best_unet_brats.pth

The available 2D demo generates tumour segmentation predictions.

3. Implemented 2D Features

  • MRI slice upload and prediction.
  • Ground-truth and predicted mask comparison.
  • Dice and IoU evaluation.
  • Segmentation overlay visualization.
  • Tumour area and area percentage.
  • Connected region count and largest region area.
  • Perimeter and eccentricity measurements.

4. Features Not Yet Implemented

  • Trained tumour classification model.
  • Grad-CAM++ explainability.
  • Verified 3D visualization.
  • Independent model performance validation.
Important: This platform is an academic research prototype. It must not be used for medical diagnosis or treatment.
