Metric definitions
Dice = 2·TP / (2·TP + FP + FN) · IoU = TP / (TP + FP + FN) · Precision = TP / (TP + FP) · Recall = TP / (TP + FN) · Specificity = TN / (TN + FP) · HD95 = 95th percentile of symmetric surface distances (mm). Undefined values (empty masks) are reported as N/A, never as 0 or 1. Classification metrics (accuracy, F1, confusion matrix) are unavailable because no classifier exists. A valid generalisation estimate needs a patient-wise held-out cohort – see docs/MODEL_DETAILS.md and experiments/.
